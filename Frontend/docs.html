Achievely is a live Steam achievement tracker. No sign-up, no linked account — just your SteamID, your library, and the achievements you've already earned, rendered fast and kept on your device.

Common

Getting started

The whole setup is one field. Nothing to register, nothing to link.

No account system

Achievely never asks you to sign up. Paste a SteamID64 and your profile loads — that's the entire flow.

Saved to your device

Your SteamID and view preferences persist in localStorage, so returning to Achievely picks up right where you left off.

Built for on the go

Fast lookups and a responsive layout mean Achievely works as well checking one achievement mid-session as it does browsing your whole library.

Core features

Everything you need to make sense of a game's achievement list, at a glance.

Keyword search

Search achievements by name across a game's full list instead of scrolling through every entry.

Rarity filter chips

Filter by how rare each achievement is across the Steam community, from common to ultra-rare.

Last-played timestamps

Relative, touch-friendly timestamps show when you last picked up a game — tap for the exact date on mobile.

Store & platform icons

Inline SVG icons render per-platform, including a hand-built Xbox glyph for the one icon missing from SimpleIcons.

Drag-to-scroll

Game rails and lists support pointer-based drag scrolling, so browsing feels native on trackpad and touch alike.

Lazy-loaded imagery

Game art and covers load in as they enter view via IntersectionObserver, keeping long libraries fast.

Rare

Release calendar

A full month grid for tracking what's coming out and when.

The calendar lays out upcoming releases across a responsive month grid, sorted alphabetically within each day. Tapping into a day opens a detail view — a modal on desktop, a bottom sheet on mobile — with hover animations that make browsing a busy month feel light rather than cluttered.

Legendary

Architecture

What's actually running underneath.

Server
Express, deployed on Render.
Caching layer
Redis via Upstash — backs both achievement data and rendered share cards.
Game data
RAWG API for release info, covers, and metadata.
Persistence
No database for user data — SteamID and preferences live in the browser's localStorage by design.
