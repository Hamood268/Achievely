API REFERENCE

Everything the client can ask the server for.

Ten routes across two resources. No auth headers, no API keys from the client — every lookup runs off a SteamID or an appId, cached behind Redis so repeat calls stay cheap.

Base URL https://achievely.onrender.com/api
Auth
None from the client. Server holds the Steam Web API key.
Caching
Cached in Redis (Upstash). TTLs range from 30 min to 24h depending on the endpoint.
Format
All responses are JSON with a code / status envelope.

Returns the player's owned games, sorted by playtime descending, paginated server-side. The full sorted library is cached for 30 minutes per SteamID; pages are sliced from that cached list, so paging through doesn't cost extra Steam API calls.

Query parameters

Games

Discovery, browsing, and achievement lists — keyed by RAWG's internal gameId or a Steam appId, depending on the route.

GET /search Search the RAWG catalog

Case-insensitive search against RAWG, up to 15 results. Query is trimmed and lowercased before matching or hitting the cache. Cached per normalized query for 24 hours.

Query parameters
NameLocationDescription
qquerySearch term. Required. Fewer than 2 characters returns an empty result set rather than an error.
Responses
200 OK 400 Bad Request 404 Not Found 500 Internal Server Error 
{
  "code": 200,
  "status": "OK",
  "count": 3,
  "games": [
    { "rawgId": 3498, "name": "Grand Theft Auto V", "slug": "grand-theft-auto-v", "cover": "https://…" }
  ]
}

Under 2 characters → 200 with count: 0 and a message prompting more input, not an error. No results at all → 404.

GET /trending Top-rated, deduped

GET /upcoming Two modes: feed or calendar month

Runs in one of two modes depending on whether month / year are provided.

No params ("legacy" mode) — a flat upcoming-releases feed from tomorrow through December 31st of the current year. Cached as upcoming:games for 6 hours.

With month + year ("calendar" mode) — every release across that specific month, up to 120 games (3 RAWG pages). Powers the release calendar. Cached per month for 6 hours.

Query parameters
NameLocationDescription
monthqueryoptional — 1–12. Switches to calendar mode; must be paired with year.
yearqueryoptional — switches to calendar mode; must be paired with month.
Calendar-mode validation
RuleResponse
Missing or out-of-range month/year400 · A valid month (1-12) and year are required.
Requested month is in the past400 · Cannot fetch upcoming games for a past month.
Requested month is more than 12 months out400 · Cannot fetch upcoming games more than 12 months ahead.
Responses
200 OK 400 Bad Request 500 Internal Server Error 
// legacy mode
{
  "code": 200, "status": "OK", "count": 30,
  "games": [
    { "rawgId": 5104, "name": "…", "slug": "…", "released": "2026-11-14", "cover": "https://…" }
  ]
}

// calendar mode — GET /upcoming?month=11&year=2026
{
  "code": 200, "status": "OK",
  "month": 11, "year": 2026, "count": 84,
  "truncated": false, // true if the month had >120 releases
  "games": [
    { "rawgId": 5104, "name": "…", "slug": "…", "released": "2026-11-14", "platforms": ["PC", "PlayStation"], "cover": "https://…" }
  ]
}
GET /games/:gameId/achievements Achievements, via RAWG → Steam lookup

Looks up the game's Steam store entry through RAWG, resolves its Steam appId, then fetches achievement data. Pass steamId to include that player's unlock state; omit it for a plain achievement list. Cached (on success) for 24 hours, keyed by SteamID when one is given.

Path parameters
NameLocationDescription
gameIdpathRAWG game id. Required.
Query parameters
NameLocationDescription
steamIdqueryoptional — SteamID64. When present, each achievement includes completed and unlocked_at for that player.
Responses
200 OK 404 Not Found 500 Internal Server Error 
{
  "code": 200,
  "status": "OK",
  "count": 167,
  "hasPlayerData": true, // true only if steamId was passed
  "achievements": [
    {
      "id": "WIN_ONE_GAME",
      "name": "First Blood",
      "description": "Win a match.",
      "isHidden": false,
      "unlocked_at": 1706812800, // null if not unlocked, or no steamId given
      "icon": "https://…",
      "iconIncomplete": "https://…",
      "completed": true,       // null if no steamId given
      "completionPercentage": 62.4
    }
  ]
}

Not on Steam, or no resolvable Steam appId → 200 with count: 0, steamAppId: null, an explanatory message, and an empty achievements array — not an error. A game with zero Steam achievements returns the same shape. Genuine 404 only fires when Steam itself has no achievement schema for the resolved appId.

GET /games/:gameId Full game detail page

The full detail view for one game — RAWG metadata merged with Steam store data (price, DLC, screenshots) where a Steam appId resolves. The whole payload is cached for 24 hours, but price is cached separately for 30 minutes and re-fetched fresh on every cache hit, so pricing doesn't go stale for a full day. Routed after /games/:gameId/achievements so the more specific route isn't shadowed.
